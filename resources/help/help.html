QtThermal — User Guide

QtThermal displays live video and radiometric temperature data from P3-series USB thermal cameras and can perform lock-in thermography to reveal very small temperature changes.

Getting started

Install the USB driver

The camera must be bound to a libusb-compatible driver.

  • Windows: use Zadig. Choose Options → List All Devices, select the camera (VID 3474, PID 45A2 for P3 or 45C2 for P1) and replace its driver with WinUSB.
  • Linux: add a udev rule granting non-root access, for example: 
    SUBSYSTEM=="usb", ATTR{idVendor}=="3474", ATTR{idProduct}=="45a2", MODE="0666"
    then reload the rules with udevadm control --reload-rules && udevadm trigger.

Start the application

  • QtThermal — use the P3 camera (default).
  • QtThermal --model p1 — use the P1 camera.
  • QtThermal --simulate — run without hardware using a synthetic image, useful for exploring the interface.

After launch the status bar and the image area show Connecting... while the application opens the device and starts the video stream. The first received frame switches the status to Connected and replaces the placeholder with live video.

The main window

Thermal view
The centre of the window shows the live thermal image with an optional temperature colour bar, centre reticule and hotspot markers.
Status bar
On the right it shows the connection state (Connecting..., Connected or Disconnected), the temperature at the centre, and the frame rate. When not connected the view shows No signal.
Menu bar
Every function is available from the menus; no keyboard shortcuts are required for the camera functions.

Feature reference

File

Save Screenshot...
Saves the current on-screen image (with overlays) as a PNG file.
Dump Raw Data...
Saves the current 16-bit thermal frame as a PGM file that preserves the raw sensor values for later analysis.
Quit
Closes the application; all settings are stored automatically.

View

Colormap
Selects the false-colour palette: White Hot, Black Hot, Rainbow, Ironbow, Military or Sepia.
Rotation
Rotates the view by 0°, 90°, 180° or 270°.
Mirror
Flips the image horizontally.
Zoom
Magnifies the image from 1x to 5x.
Interpolation
Controls how the image is smoothed when it is enlarged 2x: Off, Nearest, Bilinear, Bicubic or Lanczos.
Reticule
Shows a centre crosshair with the temperature at that point.
Colorbar
Shows a vertical temperature scale using the active colormap.
Hotspots
Marks the hottest and/or coldest point in the scene with a box and value.
Help Overlay
Draws a short reminder of where the main functions live.
Full Screen
Expands the window to fill the screen.

Processing

AGC — Factory
Uses the camera's built-in automatic gain control. This is the most responsive mode and the usual choice for general viewing.
AGC — Temporal
Normalises the image using smoothed percentile bounds so the contrast adapts to the scene without the hardware AGC.
AGC — Fixed Range
Maps a fixed temperature window (for example 10–40 °C) onto the full colour scale. The window is chosen with Fixed Range...; anything below the minimum is black and anything above the maximum is white.
Enhanced (CLAHE + DDE)
Applies local contrast enhancement and edge sharpening to reveal fine detail.
Detail Enhancement (DDE)
Sharpens edges (unsharp masking) without the local contrast step.
Temporal Noise Reduction
Blends successive frames to reduce noise; moving objects are slightly softened.
Emissivity
Sets the surface emissivity used for temperature correction, either from common presets or a custom value.

Camera

Model
Selects the connected camera model (P1 or P3) and reconnects.
Reconnect
Restarts the device connection and video stream.
Trigger Shutter/NUC
Performs a non-uniformity correction (a shutter calibration). The camera also does this automatically about every 90 seconds.
Gain
High gain is more sensitive (-20 to 150 °C); Low gain covers a wider range (0 to 550 °C).
Device Information...
Shows the model, firmware, part number, serial and hardware revision.

Lock-In

Start / Stop
Begins or ends a lock-in thermography integration. The result is shown as a 2×2 grid of panes (in-phase, quadrature, amplitude, phase) next to the thermal image.
Configure...
Edits the serial port, baud rate, period, integration time and output inversion of the external load controller.

Glossary

AGC (Automatic Gain Control)
Automatically maps the scene's temperature range onto the available display levels so the image is neither washed out nor too dark.
NUC / Shutter
Non-Uniformity Correction. The camera briefly closes its shutter to re-calibrate the sensor and remove fixed-pattern noise.
Emissivity
How efficiently a surface radiates infrared energy, from 0 (perfect mirror) to 1 (perfect black body). Correct values give accurate temperatures; shiny metal surfaces have low emissivity and are hard to measure.
Reflected temperature
The background temperature that a low-emissivity surface reflects; used together with emissivity in the correction formula.
DDE (Digital Detail Enhancement)
Edge sharpening that makes small details easier to see.
CLAHE
Contrast Limited Adaptive Histogram Equalisation; boosts local contrast without over-amplifying noise.
TNR (Temporal Noise Reduction)
Reduces random frame-to-frame noise by blending consecutive frames.
Gain mode
A sensor setting that trades temperature range for sensitivity. High gain resolves smaller differences over a narrower range; Low gain covers higher temperatures.
Lock-in thermography
A technique that switches a device's power on and off and integrates the camera signal in sync with that switching, revealing heating far below the camera's noise floor.
Reticule
The crosshair marking the centre of the image, where the spot temperature is measured.
Colorbar
A legend that maps colours in the image to temperatures.
Hotspot
The hottest (or coldest) point in the scene, marked automatically.
Interpolation (scale mode)
The filter used when enlarging the image; smoother modes look nicer, Nearest keeps hard pixels.
Radiometric
Data that contains calibrated temperature information rather than only brightness.
Scene range
The coldest and hottest temperatures currently visible in the image.
FPS
Frames per second; how many images the camera delivers each second (roughly 25 for these cameras).

Tips and troubleshooting

Tips

  • Let the camera warm up for about five minutes, then trigger a shutter/NUC for the most accurate readings.
  • In Fixed Range mode, use the Fixed Range... dialog: it shows the current scene range so you can pick a window that contains it (for example 15–25 °C in a room that is about 18 °C). A window that is entirely above or below the scene makes the image black.
  • Set the emissivity to match the material you are measuring. The correction is only reliable for emissivity above about 0.6.
  • Use lock-in thermography when you need to see changes smaller than the camera's normal noise; it needs an external controller on a serial port.
  • All options, including the window size and position, are remembered between sessions.
  • Save a raw dump (PGM) when you want to analyse the exact 16-bit values later.

Troubleshooting

The status stays on "Connecting..."
The USB handshake takes a few seconds. If it never completes, check the cable and port, and make sure no other application is using the camera.
"Camera not found"
The device is not bound to the correct driver. Re-install WinUSB with Zadig on Windows, or check the udev rule on Linux.
The image is purple or full of garbage
The USB stream is in a bad state; use Camera → Reconnect or unplug and replug the camera.
The temperatures drift
Trigger a shutter/NUC and allow the camera to reach a stable temperature.
The image is black in Fixed Range mode
The chosen window does not contain the scene. Open Processing → AGC → Fixed Range..., check the scene hint and widen or move the window.
